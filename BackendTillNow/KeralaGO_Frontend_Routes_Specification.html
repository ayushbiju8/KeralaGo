KeralaGO — Frontend Routing & Security Specification

Production-Ready Screen Navigation, Role-Based Access Control & Architecture Blueprint

Framework: React Native / Expo Router v4
App Root: app/src/app
Auth: JWT Bearer Token (SecureStore)
Roles: USER (Customer) | DRIVER (Partner)

1. Role-Based Access Control (RBAC) Architecture

The mobile app implements a strict two-tier route guard at root _layout.tsx:

  • Authentication Check: Validates presence of a non-expired JWT Access Token stored in expo-secure-store. If expired, triggers auto-refresh. If unauthenticated, user is restricted strictly to the (auth) group.
  • Role Separation: Users with role USER are restricted strictly to (customer)/*. Drivers with role DRIVER are checked for KYC approval (PENDING directs to onboarding; APPROVED unlocks operational duty).

4. Production Frontend Implementation Checklist

  • Secure Token Storage: Store JWT Access & Refresh tokens in expo-secure-store.
  • WebSocket Stream: Single persistent connection handling live location pings and ride offer broadcasts.
  • Background Geolocation: Driver app background tracking via expo-location + expo-task-manager.
  • Push Notifications: Firebase Cloud Messaging (FCM) integration with deep link route forwarding.
  • Offline Cache: React Query persistent storage for trip receipts, profile, and emergency contacts.
